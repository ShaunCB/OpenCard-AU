# Implementation Plan: Mandatory UX Enhancements

## Root Cause Analysis & Technical Constraints
1. **Markdown Table Limitations:** The current Recommender UI parses a raw Markdown table generated by the AI. While we can hack mobile responsiveness into a Markdown table using complex CSS `display: block` rules, dynamically binding `applicationUri` links, injecting conditional logic for the top 2 cards vs. others, and applying programmatic color coding (green for negative costs) is extremely brittle and error-prone when relying on an LLM to generate raw HTML/Markdown strings.
2. **Architectural Shift:** To cleanly and robustly implement these precise UI/UX features, the Synthesizer Agent must stop outputting Markdown and instead output a **Structured JSON Object**. This allows the React frontend (`RecommendationModal.js`) to take full control of rendering, natively supporting responsive CSS Grids, mobile flex-cards, conditional CTA buttons, and precise color-coding logic.
3. **Data Availability:** The `applicationUri` is currently stripped out by `minifyCdrData` in `worker.js` to save tokens. It must be added back so the AI can return it in the JSON for the frontend to bind to the Apply Now buttons.

## Target Files
- **Modified:** `worker.js` (Update `minifyCdrData` to include `applicationUri`. Rewrite `run_synth` prompt to mandate strict JSON output adhering to a defined schema instead of Markdown).
- **Modified:** `src/components/recommendation/RecommendationModal.js` (Replace `dangerouslySetInnerHTML` with a custom React render tree that handles the JSON payload. Build a responsive layout that displays as a comparison grid on desktop and stacks into distinct product cards on mobile `<768px`. Implement the dynamic color coding for `estNetAnnualCost`, the dynamic CTA buttons, and the placeholder image fallback).

## Persona Delegation
- **Frontend & UX Architect:** Will completely redesign the results view in `RecommendationModal.js` using React components, ensuring flawless responsive behavior (table-like on desktop, card-stack on mobile) and elegant presentation of the new CTAs.
- **Backend & API Engineer:** Will engineer the JSON schema prompt in `worker.js` and ensure the Gemini Synthesizer agent perfectly adheres to it.

## Cost Governance & Model Strategy
- **Tier 1 (Google AI Pro via Native Subscription):** We will use **Gemini 2.5 Pro** for the heavy lifting of writing the complex React rendering code and CSS.
- **Worker AI:** The `worker.js` Synthesizer will continue using `google/gemini-2.5-flash`. Flash is exceptionally good at structured JSON generation (JSON mode natively), making it perfect for this architectural shift.

## Step-by-Step Execution Plan
1. **Worker Update (Data prep):** Modify `minifyCdrData` in `worker.js` to extract and keep `product.applicationUri`.
2. **Worker Update (Synthesizer Prompt):** Rewrite the `run_synth` prompt. Instruct it to output a JSON string matching this schema:
   ```json
   {
     "disclaimer": "...",
     "goalSummary": "...",
     "verificationChecklist": ["..."],
     "cards": [
       {
         "id": "...", "name": "...", "brand": "...", "image": "...", "applicationUri": "...",
         "eligibility": "...", "annualFee": "...", 
         "estAnnualInterest": { "display": "...", "explanation": "..." },
         "estRewardValue": { "display": "...", "explanation": "..." },
         "estNetAnnualCost": { "display": "...", "numValue": -150, "explanation": "..." },
         "keyRisks": ["...", "..."],
         "goalAlignment": "..."
       }
     ],
     "topPickReason": "...",
     "dataGaps": ["..."]
   }
   ```
3. **Frontend UI Update (`RecommendationModal.js`):**
   - Parse the JSON recommendation instead of using `marked`.
   - Build a `div`-based responsive grid layout. 
   - **Desktop (<768px):** Use standard flex-column for cards.
   - **Desktop (>768px):** Use CSS Grid (`grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))`) or a flex row to display cards side-by-side.
   - Inject the `infoModalState` trigger directly on an `IconButton` or text span instead of using delegated markdown clicks.
   - Implement the `estNetAnnualCost.numValue < 0` logic to apply green text coloring (and white/grey otherwise).
   - Implement the Top 2 index logic to render `Apply Now` vs `More Info` buttons.
   - Implement a fallback placeholder image if `cardArt` is missing.
4. **Self-Testing:** Run terminal commands to stage, commit, and push. Visual QA can be performed once Cloudflare deploys.
